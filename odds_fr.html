Remarques générales

  • Toutes les probabilités sont exprimées en pourcentage (%), et s’appliquent, à chaque lot d’une invocation, de façon indépendante de toutes les autres invocations.
  • Les probabilités sont déterminées en tirant d’abord le grade, puis en tirant un exemplaire au sein de ce grade avec une probabilité égale — les valeurs du tableau sont les probabilités de chaque Grade ; la probabilité d’un seul exemplaire est de probabilité du grade ÷ nombre de types dans ce grade.
  • Pour les invocations, un mécanisme (pitié/garantie) qui garantit un grade supérieur après un nombre fixé d’invocations n’est pas proposé. Pour les équipements, les compétences et les alliés, le Niveau d’invocation n’est pas une attribution garantie ; c’est un mécanisme grâce auquel la table de probabilités elle-même s’améliore — toutes ces valeurs figurent dans le tableau par niveau de chaque rubrique.
  • Les probabilités des tableaux sont arrondies ; leur somme peut donc différer légèrement de 100 % dans les décimales.
  • Si les probabilités sont modifiées, les modifications et leur date d’application seront annoncées à l’avance.
