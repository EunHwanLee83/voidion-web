공개 페이지(game.voidion.kr) 이미지

  bg.jpg    — 전체 배경 (1920x1080 이상 권장, JPG). 가운데가 비어 보이는 그림이 좋다.
              ⚠️ 화면 가운데에 카드가 얹히므로, 중요한 그림은 좌우로 두는 편이 낫다.
              ⚠️ 용량 500KB 이하 권장 — GitHub Pages 는 CDN 이지만 첫 로딩에 그대로 실린다.

  icon.png  — 앱 아이콘 (512x512 정사각 PNG). 제목 오른쪽 + 브라우저 탭 + 카톡 미리보기에 쓰인다.

두 파일 다 없어도 페이지는 그대로 뜬다 (배경은 단색, 아이콘은 사라진다).
넣은 뒤 `bash web/publish.sh` 로 발행한다.
